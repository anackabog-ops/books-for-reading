# Pasikalbėkime! · Bozhena Anacka

Разговорный урок: 100 авторских вопросов на литовском, 10 тем, русские переводы и подсказки для ответа. Ориентировочные уровни: 30 A1, 40 A2, 30 B1. Это учебная подборка, не стандартизированный экзамен. Некоторые знакомые разговорные формулы с условным наклонением встречаются уже в A1–A2; подсказки помогают их использовать.

## Запуск

Статический сайт без сборки и внешних JavaScript-зависимостей. Из этой папки:

```sh
python3 -m http.server 17876
```

Открыть `http://localhost:17876`. При размещении папки в корне GitHub Pages урок открывается по пути `/books-for-reading/pasikalbekime/`. Нужен HTTP/HTTPS; не открывать HTML через `file://`.

## Функции

- Тематические колоды, уровни A1/A2/B1, перемешивание без повторов до конца круга.
- История текущей колоды с кнопкой «Назад»; перевод и подсказка сбрасываются при смене вопроса.
- Избранное, повторение и письменные ответы сохраняются в localStorage текущего браузера.
- Собственные картинки на вопрос или тему сохраняются в IndexedDB текущего браузера. Эти картинки не публикуются и не синхронизируются с учениками. Картинка вопроса имеет приоритет над темой. Удаление картинки вопроса возвращает картинку темы, если она есть.
- 10 авторских тематических стикеров в сливочно-голубой гамме с зелёными акцентами. В сцене общения представлены мужчины и женщины разных возрастов.
- Уважение настройки уменьшения анимации; клавиатурные элементы управления и мобильная вёрстка.

## Озвучка: текущий статус

`audio.json` пока пуст: записи Azure ещё НЕ созданы. Урок использует только явно доступный литовский голос устройства, если браузер его предоставляет. Когда такого голоса нет, кнопка неактивна с пояснением. Браузерный голос не обозначается как Azure.

Для постоянной одинаковой озвучки всех вопросов подготовлен `scripts/generate-audio.py`. Используется существующий формат приватного файла `~/.azure/lietuviskos-knygos-speech.json` с полями `sku`, `SPEECH_KEY`, `SPEECH_REGION`. Файл должен оставаться вне репозитория. Генератор принимает только ресурс с `sku: F0`, прекращает работу при ошибке квоты и не переключается на платный ресурс. Нужен ffprobe (из FFmpeg).

```sh
python3 scripts/generate-audio.py --check-only
python3 scripts/generate-audio.py --limit 10
python3 scripts/generate-audio.py
```

По умолчанию голос `lt-LT-OnaNeural`, также доступен `--voice lt-LT-LeonasNeural`. Хешированные MP3 кэшируются по тексту и голосу. Манифест записывается после каждого успешно проверенного файла. Изменённый вопрос не воспроизводит старую запись: интерфейс сверяет текст с манифестом. При воспроизведении сайт не обращается к Azure.

После генерации нужно прослушать записи и опубликовать `assets/audio/` вместе с `audio.json`. Кнопка 0,8× замедляет воспроизведение. Никакого распознавания или автоматической оценки речи нет.

Документация API: https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-text-to-speech

## Содержание и оформление

`questions.json` — единственный источник данных для интерфейса. Изменять вопросы, перевод, подсказки и темы здесь. Не менять стабильные ID без необходимости: к ним привязаны ответы, избранное и картинки. `questions-source.txt` — исходный редакционный черновик; после правок JSON он не используется приложением.

`assets/stickers.webp` — сгенерированный атлас, показанные области заданы в `topics[].region`. Промпт финальной редакции: hand drawn watercolor and pencil adult conversation lesson sticker atlas, 5×2 cells, minimalist powder blue and creamy ivory with green accents; personal journal, inclusive group of four adults of different ages, armchair with cat, tea and croissant, Vilnius, suitcase, notebook, watercolor palette, camera, seedling. Изображение создано встроенной генерацией изображений и доработано по пожеланиям автора.
