# Озвучка Kol mokausi gyventi через GitHub

Текст и подготовка озвучки находятся в черновике PR #1. Аудио пока не создано.

## Автоматическая проверка

Workflow **Kol mokausi - text and speech preparation** проверяет Python и читалку, очистку JSON, все 18 глав, 963 фрагмента, 5 947 слов и пояснений, а также соответствие SSML тексту и закладкам. Он не обращается к Azure. Результат доступен в артефакте **kol-mokausi-speech-preparation** внизу страницы успешного запуска Actions. Это техническая проверка, а не подтверждение правильности всех ударений или переводов.

## Однократная настройка озвучки

1. В Azure откройте свой ресурс Speech и проверьте тариф **Free F0**.
2. В репозитории откройте **Settings → Secrets and variables → Actions → Secrets**.
3. Добавьте **AZURE_SPEECH_KEY** и **AZURE_SPEECH_REGION** из страницы **Keys and Endpoint** ресурса Speech. Ключ не нужно отправлять в чат или сохранять в файлах репозитория.
4. На вкладке **Variables** добавьте **AZURE_SPEECH_SKU** со значением **F0**.

Проверка F0 опирается на вашу проверку тарифа и указанное значение; сам Speech-ключ не позволяет этому скрипту запросить тариф в Azure Resource Manager. Скрипт не переключает тариф и останавливается при ошибке сервиса, включая исчерпание доступной квоты.

## Ручной запуск

GitHub требует, чтобы файл workflow существовал в основной ветке, прежде чем разрешит workflow_dispatch. Пока файл только в черновой ветке, кнопка ручного запуска может быть недоступна. Не сливайте всю книгу до проверки аудио только ради этой кнопки: файлы автоматизации можно отдельно перенести в main, сохранив книгу в черновике. Затем выберите в Actions workflow **Kol mokausi - Azure narration**, нажмите **Run workflow** и выберите ветку **codex/kol-mokausi-gyventi-pilot**, содержащую полную книгу и скрипты.

Подтвердите, что проверили тариф F0. Запуск последовательно создаст озвучку 18 глав. Обычные изменения текста не запускают Azure.

Голоса: Ona — рассказчица и женские реплики, Leonas — проверенные мужские реплики. Авторские вставки остаются голосом рассказчицы.

## Результат и повторный запуск

Скачайте артефакт **kol-mokausi-audio-review-…**. Он содержит канонический JSON со ссылками на звук, MP3 глав и предложений, манифесты и отчёт. Только зелёный запуск с успешным шагом **Verify every recording and decode all MP3s** подтверждает техническую полноту всех записей. Артефакт красного запуска может содержать лишь часть глав.

Синтез кэшируется по SSML. После ошибки повторный запуск на той же ветке использует сохранённые записи, если GitHub сохранил кэш. Кэши могут истечь или быть удалены; при отсутствии кэша запросы будут повторены. Артефакты хранятся 30 дней — скачайте нужный результат. Автоматическое добавление аудио в Git и публикация не выполняются.

После получения аудио нужно прослушать произношение (в том числе имя Samira), проверить синхронизацию и читалку на телефоне, внести проверенные файлы из артефакта в ветку книги, актуализировать статус обработки и лишь затем завершить выпуск. Технический отчёт не заменяет эти проверки.

Документация: https://docs.github.com/en/actions/how-tos/manage-workflow-runs/manually-run-a-workflow
